# Contributors & Open Source Usage 

This Docusaurus runtime was designed and developed for Temple University CIS project courses. It is built on the shoulders of students, alumni, faculty, and open source software. This page is automatically generated from the package `package.json` file and provides a list of the projects and plugins that make this template possible.

<Contributors orgName="applebaumian" projectName="tu-cis-4398-docs-template"/>

We welcome contributions from Temple University students, and alumni! If you'd like to contribute, please:

1. Fork the [template repository](https://github.com/ApplebaumIan/tu-cis-4398-docs-template)
2. Create a feature branch
3. Submit a pull request

All contributors will be recognized here.
